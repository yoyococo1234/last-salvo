## 这是什么

玩家从两条出兵线进入战场，占领资源点换取金币，随时换装坦克、炮艇或战机，
**先到 1500 胜利点的一方获胜**。单局约 15 分钟。

核心设计是**用金币经济给「复活」定价**：死亡后不会自动复活，必须回车库花金币买新的，
而价格随死亡次数与换车次数递增（1.05^N，封顶 1.5 倍）。
于是「什么时候上什么车」成为真正的策略决策，而不是比枪法。

### 三域同场

六个载具共用一张战场，但作战逻辑完全不同：坦克吃地形与装甲角度，炮艇受水深与航速约束，
飞机有独立的飞行模型与姿态仪。三者共用一套**穿深 / 装甲 / 模块毁伤**规则，
所以「舰炮打坦克」和「机炮打飞机」都有真实的命中与跳弹判定。

| 载具 | 域 | 血量 | 价 | 主武器 | 副武器 |
|---|---|---|---|---|---|
| 轻坦 | 陆 | 800 | 140 | 75mm（180 / 3s / 700m） | 12.7mm 机枪 |
| 主战坦克 | 陆 | 1200 | 220 | 120mm（300 / 4.5s / 1200m） | 12.7mm 机枪 |
| 重装坦克 | 陆 | 1600 | 260 | 130mm（420 / 6s / 900m） | 12.7mm 机枪 |
| 炮艇 | 海 | 4500 | 320 | 舰炮（420 / 4s / 1300m，破甲弹） | 鱼雷 + 12.7mm |
| 战斗机 | 空 | 300 | 180 | 20mm 机炮（4.5 / 0.15s / 800m） | 空空导弹 ×1 |
| 攻击机 | 空 | 450 | 240 | 20mm 机炮 | 反坦克导弹 ×8 |

### 金币经济

```
实际车价 = 原价 × 1.05^死亡次数 × 1.05^换车次数     （总倍率封顶 1.5）
旧车回收 = 当时实际买入价 × 50%
买单顺序：gold += 回收;  gold -= 车价
```

买不起的车卡会写「还差 N 金」并且点不动。

### 灵魂模式

连最便宜的车都买不起时，可以升空进入**灵魂模式**，自由飞行俯瞰整个战场，
观察敌方动向与据点压力，等金币够了再落回去。死亡不是罚站，而是获得信息的窗口。

### 人数可配

「游戏调整」面板里可按载具类型分别设置敌我数量（每类 0~6 台）。
默认每方 20 台 AI + 玩家，三域混编。

## 运行

### 直接玩（Windows）

到 [Releases](../../releases) 下载最新构建，解压后双击 `LastSalvo.exe`，无需安装。

> Windows 10/11 64 位。需要一块能跑 3D 的显卡。

### 打开工程

用 **Unity 6000.3.27f1** 打开本目录（Unity Hub → Add project from disk）。

- 渲染管线：Built-in（不是 URP）
- 输入：旧 Input Manager（`activeInputHandler = 0`）
- 主场景：`Assets/Scenes/Map_Battlefield.unity`
- 若只跑编辑器，不需要额外的打包模块

### 操作

| 功能 | 默认键 |
|---|---|
| 前进 / 后退 / 左右 | W / S / A / D |
| 开火 | 空格 或 鼠标左键 |
| 开镜 / 拉近 | Shift 或 鼠标右键 |
| 自由视角 | C |
| 切换武器 | Q |
| 机枪模式 | V |
| 锁定目标 | Ctrl |
| 补给商店 | Tab |
| 暂停 | P |
| 回车库 / 弃车 | G |
| 灵魂出窍（观战） | O |
| 干扰弹（船） | X |
| 一键改平（飞机） | F |

按键全部可在「按键设置」里改。

## Aholo Lux3D 的应用

Lux3D 在本项目里不是「贴图素材工具」，而是**全部可见资产的唯一来源**：
6 台可驾驶载具、废墟建筑、路障、地标物件，全部由 Lux3D 生成 GLB 后接入 Unity。
地形、物理、AI 是程序化实现。

```
锁定风格模板 → Lux3D 生成 GLB（按车体/炮塔/炮管/履带分件）
            → Blender 转 FBX（统一轴向与缩放）
            → Unity 挂 VehicleDef 数据资产
            → 运行时装配（程序化履带、炮塔井补面、挂点自适应）
```

两条关键经验：

1. **一致性靠锁死提示词模板**，不是靠反复重试。
2. **可装配性靠分件生成** —— 车体、炮塔、炮管、履带分开出，才能在引擎里做独立旋转、
   俯仰、程序化履带。一次成型整台出的模型看起来漂亮，但接不进需要动起来的系统。

## 技术栈

| 项 | 值 |
|---|---|
| 引擎 | Unity 6000.3.27f1 |
| 渲染管线 | Built-in Render Pipeline |
| 输入 | 旧 Input Manager |
| 代码规模 | 约 1.4 万行 C#（含编辑器工具链） |
| 战场规模 | 2000 × 2000 m，4 张地形瓦片，场景对象约 4500 个 |
| 海面 | Crest FFT 波浪 + 平面反射 |
| 3D 资产 | Aholo Lux3D 生成 → Blender 转换 → Unity 接入 |
