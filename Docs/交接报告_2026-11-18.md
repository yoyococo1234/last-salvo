## 3. 🔴 这个项目最大的陷阱：三处会覆盖你改的值

今天在这上面栽了三次，全记下来：

### ① 场景序列化覆盖脚本默认值

`Map_Battlefield.unity` 里存着的值会**覆盖** `= xxxf` 的代码默认值。

已确认被序列化的：`airRollFollow`、`airLookDownDeg`、`airHeightFactor`、`airDistanceFactor`、`airRollSmooth`

**查法**：
```powershell
Select-String -Path Assets\Scenes\Map_Battlefield.unity -Pattern "你的字段名"
```

**改法**（必须用 MCP，改脚本没用）：
```
objects | get components | where $ is CameraFollow | set airRollFollow = 0.12
editor | call SaveScenes()
```

### ② `DataSeeder` 会覆盖 `.asset`

跑「Tools/铁皮黎明/生成默认数据」会重写整个 `Assets/Data/`。
**改任何 `.asset` 数值时必须同步改 `DataSeeder.cs`**，否则下次跑就冲掉。

### ③ 静态缓存

`WingStores._cache` 按机型缓存机翼采样，改了模型/缩放要 `ClearCache()`。
