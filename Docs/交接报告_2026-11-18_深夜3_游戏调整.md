## 1. 「飞机开局就开放」与「空战解锁时间」重复 → 删掉前者

两者控制的是同一件事：
```csharp
// 旧 DomainUnlocked()
if (AirFromStart) return true;             // 开关说"开局就开"
if (UnlockMinutes <= 0) return true;       // 倒计时说"0 分钟也开"
```
同时开着两个 UI，玩家不知道以谁为准。

**处理**：`MatchSettings.AirFromStart` 字段**整个删除**（不是只藏 UI），语义并进 `UnlockMinutes`：

```csharp
public static bool DomainUnlocked(Domain d)
{
    if (d != Domain.Air) return true;
    if (UnlockMinutes <= 0) return true;       // 0 = 开局全开
    return MatchElapsed >= UnlockMinutes * 60f;
}
```

⚠️ **老存档迁移（必做）**：以前存过 `airFromStart=1` 的玩家，光删字段会变成
"飞机永远不开放"（开关没了、分钟数还停在 3）。`Load()` 里补了：
```csharp
bool legacyAirFromStart = PlayerPrefs.GetInt(K + "airFromStart", 0) != 0;
UnlockMinutes = PlayerPrefs.GetInt(K + "unlockMin", 3);
if (legacyAirFromStart) UnlockMinutes = 0;      // 等价迁移
```

`MenuOptions` 里删掉了 `Toggle()` 方法和它的调用；`MatchManager` 里
`UnlockMinutes > 0 && !AirFromStart` → `UnlockMinutes > 0`。
面板上留一行灰字说明：**"设「开局全开」= 飞机从第一秒就能选"**。

## 2. AI 强度删掉「原版（很凶）」

```csharp
public static readonly float[]  SkillSteps = { 0.55f, 0.75f };      // 原来还有 1.0f
public static readonly string[] SkillNames = { "轻松", "普通" };     // 原来还有"原版（很凶）"
```

⚠️ **老存档迁移**：`AIDifficulty.Of()` 是按 skill 连续插值的，删档位不会崩，
但界面两档都不会亮（比较是 `Mathf.Abs(AiSkill - 0.55) < 0.001` 这种精确匹配）。
`Load()` 里加：
```csharp
if (AiSkill > 0.85f) AiSkill = 0.75f;      // 老的"原版"降成"普通"
```

## 3. 「极快」压到右栏

原来：标签占左边 200、按钮从 `lx+200` 起每个 62 宽 → 6 个排到 `lx+572`，
而左列 `lw = 500` → 最后一个「极快」**直接压进右栏的人数表**。

改成标签独占一行、按钮从 `lx` 起铺满左列：
```
6 个 × 74 宽 + 5 × 6 间距 = 474 ≤ 500   ✓
```
