## 2. 顺带挖出来的三个经济漏洞（比灵魂出窍本身更严重）

用户提"不该免费"之后我去查，发现**三个地方都在白送**：

### 漏洞 ①：最便宜的车免费

```csharp
// 旧 MatchManager.CanAfford
if (_human.gold >= def.price) return true;
return _human.gold < CheapestPrice && def.price == CheapestPrice;   // ← 一穷二白就白送
```

轻坦 160、战斗机 160 都是最便宜档 —— **死了没钱照样能开走**。

### 漏洞 ②：复活自动补钱

```csharp
// 旧 MatchManager.OpenGarageForRespawn
if (cheapest > 0 && _human.gold < cheapest)
{
    int add = cheapest - _human.gold;
    _human.gold = cheapest;            // ← 直接补到刚好够
    PushFeed($"复活补给 +{add} 金");
}
```

死了自动送钱，等于永远不缺钱。

### 漏洞 ③：没车就领不到占点收入（最隐蔽）

```csharp
// 旧 UnitState
public bool Eliminated => lives <= 0 && !HasVehicle;

// 旧 MatchManager.UpdateIncome
if (income0 > 0) foreach (var u in units) if (u.team == 0 && !u.Eliminated) u.gold += income0;
```

命数删掉后 `Eliminated` 退化成 `!HasVehicle`，于是**"没车 → 领不到占点收入"**。
配合漏洞 ①②，就变成：死了 → 白拿车 → 继续打，钱根本不用攒。

## 3. 改了什么

| 文件 | 改动 |
|---|---|
| `MatchManager.CanAfford` | **删掉免费档**，`return _human.gold >= def.price;` |
| `MatchManager.OpenGarageForRespawn` | **删掉自动补钱**，只在标题里显示"最便宜 160" |
| `UnitState` | `Eliminated` → 改名 `NoVehicle`，语义纯粹是"当前没车" |
| `MatchManager.UpdateIncome` | 收入过滤去掉，**没车也照常领** |
| `SoulCamera.CanUse()` | **新增静态判定**，唯一入口条件 |

### `SoulCamera.CanUse()` 的核心逻辑

```csharp
public static bool CanUse()
{
    // 对局进行中、不在 UI
    if (mm == null || mm.matchOver) return false;
    if (!GameStartScreen.Started) return false;
    if (PauseScreen.Paused || ShopScreen.Open) return false;
    if (GarageScreen.Instance != null && GarageScreen.Instance.IsOpen) return false;

    // ① 必须有"没车"这个前提
    var p = mm.Player;
    bool noCar = p == null || !p.Alive;
    if (!noCar) return false;

    // ② 而且买不起最便宜的车
    int cheapest = mm.CheapestPrice;
    if (cheapest <= 0) return false;
    return mm.Gold < cheapest;
}
```

`Update()` 里：满足 → 自动进入；条件失效（攒够钱 / 重新出击）→ 自动退出。
**有车时按 O 什么都不发生。**

## 6. 现在的经济闭环

```
死了 → 没钱 → 不能白拿车
     ↓
  没车 + 买不起 → 自动进灵魂视角（看战局，不干坐着）
     ↓
  没车也照常领占点收入（每 10 秒 +N）
     ↓
  攒够 160 → CanUse() 变 False，自动落地
     ↓
  按 G 进车库买车 → 出击
```

这条链路现在是**通的**，而且每个环节都有代价 —— 想快就得多占点，占点就得活着。
