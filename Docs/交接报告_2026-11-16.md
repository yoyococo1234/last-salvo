## 2. 机枪："12.7mm 能打穿主战场"是个数据 bug

**根因**：`Weapon_mg_aa.asset` 的 `ammoTypes[0]` 挂的是 **`Ammo_ap`**（就是 120mm 主炮那发，穿深 260 mm），而代码注释写的是"机枪固定用第一种子弹（防空弹）"——注释和数据对不上。

结果：12.7mm 机枪拿 260 mm 穿深打坦克，近距离能穿主战 220 mm 首上，实际 DPS 240，**是主炮（80 DPS）的 3 倍**。

**修法**：新建 `Assets/Data/Ammo/Ammo_mg.asset`（guid `98e9e05ac5fd47849c0c9d14e3ec3de2`）：

```yaml
vsArmor: 0.15     # 打装甲几乎无伤
vsSoft: 1.2
vsAir: 0.47       # 对空 60 DPS
vsSea: 0.2
penetration: 40   # 打不穿任何坦克（轻坦侧面 36 mm 勉强）
```

`Weapon_mg_aa`：`baseDamage 22 → 14`，`ammoTypes` 只保留 `Ammo_mg`。
`VehicleCombat.cs:778` 的命中音效判定加了 `"mg"`（否则机枪打中会放炮弹的"砰"）。

**改完的效果**：

| 目标 | 能穿？ | 实际 DPS | 打死要多久 |
|---|---|---|---|
| 主战坦克正面 | 不穿 | 6.7 | 180 s（等于废） |
| 轻坦侧面 | 穿 | 19 | 42 s |
| 炮艇 | 只穿侧面 | 25 | 275 s |
| 战斗机 / 攻击机 | 穿 | **60** | 5.0 / 7.5 s |

## 4. 飞机飞行手感：欧拉角 → 四元数

### 4.1 原来为什么翻不了跟头

`VehiclePhysics.UpdateAir()` 三处硬限制：

```csharp
airPitch = Mathf.Clamp(airPitch, -70f, 70f);                      // 俯仰顶死 ±70°
airRoll  = Mathf.Clamp(airRoll + rollIn*rate*dt, -85f, 85f);      // 滚转顶死 ±85°
var targetRot = Quaternion.Euler(-airPitch, airYaw, -airRoll);    // 欧拉角，过 ±90° 万向锁
```

### 4.2 调研结论（战争雷霆 / 皇牌空战 / 战地）

- **WT** 的核心是 Instructor（教官）：鼠标指示方向，教官替你操纵三舵面；**限制的是迎角 AoA（约 22~28°），不是姿态角**——所以姿态 360° 自由，能翻跟头，只是做不出"眼镜蛇"（那要关教官）。
- **皇牌空战** 分 Standard（自动转向你指的方向）/ Expert（直接控 roll+pitch）。
- **战地** 用空格/Ctrl **一键 loop**，社区评价是极好的 QoL。
- Unity 社区共识：**欧拉角不该出现在飞行系统里**。
- 参考实现：`brihernandez/MouseFlight`（MIT）的 point-and-chase law。

结论：我们本质是街机档（无失速、机头朝哪飞哪），**不需要 AoA 教官，只需要放开姿态 + 消除万向锁**。

### 4.3 改法

玩家分支改成每帧把一小步旋转**乘**到当前姿态上（AI 分支保留原欧拉角路径）：

```csharp
var rot = transform.rotation;
rot = Quaternion.AngleAxis(yawRate * dt, Vector3.up) * rot;          // 世界偏航
rot = rot * Quaternion.AngleAxis(-pitchRate * dt, Vector3.right);    // 机身俯仰
rot = rot * Quaternion.AngleAxis(-rollRate * dt, Vector3.forward);   // 机身滚转
transform.rotation = rot;
```

滚转带出转弯改用真实倾角：`Vector3.Dot(transform.up, transform.right)`。

### 4.4 参数（都在 `VehiclePhysics` 的 public 字段上）

| 参数 | 原值 | 现在 | 备注 |
|---|---|---|---|
| `airPitchRate` | 55 | **80** | 翻跟头不至于太慢 |
| `airYawRate` | 32 | **40** | |
| `airRollRate` | 120 | **110** | 中途试过 200，用户反馈"AD 转太快"，退回接近原值 |
| `airRecenterSpeed` | 0.9 | **0.5** | 长按转向不被回中顶住 |
| `airAutoLevelMaxBank` | — | **40°** | 新增，见下 |
| `airAutoLevelRate` | — | **3** | 新增 |

**松手小幅自动回正**（用户要求"小幅度的 AD 松手之后自己回正"）：A/D 都松开且倾斜 < 40° 时，把机翼缓慢摆平；超过 40° 保持不动（不然做不了桶滚/倒飞）。

### 4.5 一键改平（F 键）

`Bindings` 新增 `Act.LevelFlight`（默认 **F**），自动出现在「按键设置」里。
按住 = 机翼水平 + 机头压回水平（保留航向）。HUD 飞机界面右上角显示「F 一键改平」。

### 4.6 飞机机炮准星不在中心

`CameraFollow.airLookDownDeg` **18° → 6°**。原来相机视线比机头低 18°，而准星画的是"机头指向 900 m 外"的投影，所以准星跑到画面上方 18°。开镜时本来就是 0（居中）。

## 7. 据点

### 7.1 城区巷战据点一半泡在海里

`Zone_zone_urban.asset` 的 `bounds` 是 `Rect(x, y, width, height)`，**中心 = (x + w/2, y + h/2)**，不是 (x, y)。

```
原值：x -417, y -300, 834×834  →  实际中心 (0, +117)，半径 417
北边缘 = 117 + 417 = 534，而岸线在 z ≈ 292  →  有 240 m 伸进海里
```

改成：

```
x -300, y -330, 600×600  →  中心 (0, -30)，覆盖 z -330~270，全在陆地上
```

### 7.2 海面据点光圈比船高

`ZoneMarker.RingLift = 0.5` 对所有据点（包括水上的）都抬 0.5 m，海面有波浪，浪谷时看着就浮在船上方了。

改成分位置判断：**水上 0.06 m（几乎贴海面）/ 陆地 0.5 m**。

## 8. 鱼雷：2 倍射程才自毁

`Torpedo.cs` 原来是 `if (_travelled >= _range)` 就爆（用户猜对了）。

| 项 | 原值 | 现在 |
|---|---|---|
| 自毁距离 | 1 倍射程（600 m） | **2 倍射程（1200 m）** |
| 1~2 倍之间伤害 | 直接爆，没伤害 | **100% → 30% 线性衰减** |
| 引信寿命 `_life` | 1 倍 | 同步放到 2 倍 |
| `AcquireTarget` 搜索半径 | 600 m | **1200 m**（否则飞远了追不上） |

```csharp
float RangeDmgMul()   // 900 m 时 65%，1200 m 时 30%
{
    if (_travelled <= _range) return 1f;
    float k = Mathf.Clamp01((_travelled - _range) / _range);
    return Mathf.Lerp(1f, 0.3f, k);
}
```

## 12. 船能开上沙滩（穿模）

三个原因叠加：

**① 搁浅是"慢慢减速"** —— `MoveTowards(speed, 0, brakeDecel*dt)`，从 24 m/s 减到 0 要好几个 tick，而 `transform.position += forward * speed * dt` 一直在推进。300 m 宽又平缓的沙滩就被冲上去了。

```csharp
// 改成：正速度直接截断，只留倒车
speed = Mathf.Min(speed, 0f);
```

**② 加硬保护** —— 不许往**更浅**的地方走（水深低于半个吃水就退回上一帧位置）。只拦"变浅"，所以卡住时倒车回水里仍然允许，不会锁死。

**③ 出生点兜底太松** —— `FindSeaSpawn` 的全图扫描原来 `if (d <= 0f) continue`，10 cm 浅滩也算"能放船"。改成 **`d < 2.5f` 跳过**。

## 13. 锁定框偏上

用户反馈"按 Ctrl 的框画偏了，偏上"。

原来锚点：`Target.transform.position + Vector3.up * 1.2f` —— 船的 transform 原点在甲板附近，再 +1.2 m 就明显高于玩家看到的船体。

改成**渲染网格的合并包围盒中心**：

```csharp
static Vector3 VisualCenter(VehicleCombat v)   // 所有 Renderer.bounds 合并后取 center
```

这个算法对坦克/飞机/炮艇都成立，不依赖模型原点。

> ⚠️ **未验证**：这一版（f）是刚改的，还没人飞过。如果框还是偏，说明不是锚点问题而是相机投影，需要按"偏哪个方向、偏多少"再定位。

**`BuildCli.BuildWindows` 会读 `TANK3D_BUILD_DIR`**（`GameBuilder.BuildWindows` 是硬编码 `D:/Builds`，别用）。`OneShotRebuild.RunTerrain` 已改成走 `BuildCli`。

### 14.2 坑

- **`& Unity.exe` 在 PowerShell 里不阻塞**（GUI 程序），必须加 `| Out-Null` 或 `Start-Process -Wait`，否则 `$LASTEXITCODE` 是空的、脚本提前跑完。
- **编译验证**（15 秒）比打包便宜，改完先跑一次 `-batchmode -quit -nographics` 看 `error CS`。
- **D 盘只剩 ~29.8 GB**（低于 35 GB 底线），包一律输出到 E 盘。
- **删除旧包用回收站**（`Microsoft.VisualBasic.FileIO.FileSystem::DeleteDirectory(...,'SendToRecycleBin')`）；`Remove-Item -Recurse -Force` 在 cwd 外会被 CC Safety Net 拦。
- 改场景里 `Water_Sea` 的 Y 时，要按 `--- !u!4 &<fileID>` 定位后改那一行（`m_LocalPosition: {x: 0, y: 0, z: 0}` 在场景里出现很多次，直接替换会误改）。
- Propagate：`PropScatter` 的随机种子固定（`20261030`），地形改动只要不影响撒点区域，场景 diff 会是 0 行（这次只有水面那 2 行）。
