## 1. 灵魂视角退出 → 直接进车库

`SoulCamera.Update` 的手动退出分支原来是「只有从车库上来的才回车库」，现在是：

```csharp
Exit("手动退出");
_manualUntil = Time.unscaledTime + ManualHoldSeconds;
_mm.OpenGarageManual(fromSoul: true);     // 一律进车库
```

`fromSoul: true` 会把 `allowAutoSoul: false` 一路传进 `GarageScreen.Open()`：
**玩家刚亲手退出，车库不再倒计时把他 1.5 秒后弹回天上**（否则表现就是"按 O 完全没反应"）。

实测（MCP Play）：
```
T0: soul=False garage=True gold=75 canAfford=False
T3（3 秒后）: soul=False garage=True   ← 没被自动弹回去
```

## 2. 自动升空，不再"说一声让你点"

| 场景 | 行为 |

## 9. 追加（22:44）：又两处用户反馈

### 9.1 "这个界面按 G 回不去，按键很混乱"

两个真 bug：

**① G 键根本没有监听（没车时）**
`Bindings.Act.Garage` 只挂在 `PlayerTankController.Update` 里 —— 那是**车身上的组件**。
没车时场景里根本没有这个组件，所以按 G 完全没反应。

修：`MatchManager.Update` 加常驻兜底：
```csharp
if (Player == null && !matchOver && Bindings.Down(Bindings.Act.Garage)
    && (GarageScreen.Instance == null || !GarageScreen.Instance.IsOpen))
    OpenGarageManual();
```
有车时仍走 `PlayerTankController`（那条会先挂账旧车回收），两条路靠 `Player == null` 互斥。

**② 玩家主动开的车库被 1.5 秒后自动弹回天上**
上一轮只有"从灵魂退出"才关掉倒计时。结果"没车按 G 进车库"→ 1.5 秒又被弹走，
表现就是"按 G 回不去"。
修：`OpenGarageManual()` **固定 `allowAutoSoul: false`**，去掉 `fromSoul` 参数。
自动升空只留给系统自己弹库那条路。

同时 `SoulCamera` 里 **G 也算退出**（O / Esc / G 三者等价，都是退出后进车库）。

### 9.2 "会有字显示不清楚，一起改"

根因是全局的：**中文行高 ≈ fontSize × 1.35，而 HUD 里大量 18px 的字只给了 18~22px 的框**，
`GUI.skin.label` 默认 `clipping = Clip`，于是字被上下各切掉一截
（金币面板那行「占点全队产金 · 胜利点 0/0」就是这么糊的）。

修法分两层：

| 层 | 改动 |
|---|---|
| 全局兜底 | `MatchHUD.Style()` 里加 `st.clipping = TextClipping.Overflow` —— 字永远完整，框略欠时只微微出框，不再被切 |
| 关键面板加尺寸 | 金币面板 `250×78 → 300×84`，第二行改 15px；顶部栏 `96 → 106`，进度条上移、底行 `18px 高 → 22`；资源点行 `22 → 26` 且进度条下移；名字牌名字 `22→24`、距离 `18→22` |

**顺带修**：金币变化浮字原来画在 `x=280`（写死旧面板宽 250），面板加宽后会**压在面板第二行文字上**
（截图里 `-505` 盖着「胜利点 0/0」）。现在挪到 `x=324`（面板右边界 316 之外），
y 从 44 上浮 34 px，绝不进面板内。

验证：`Docs/UI_HUD_修字_20261118.png` —— 金币面板两行完整、顶部栏底行完整、
底部状态条只剩一行且不重叠。

## 10. 追加（22:50）：左上「退出」语义重定 + 提示条压副标题

### 10.1 左上角「退出」= 退出本局（用户明确要求）

用户原话："左上角的退出功能好像有问题啊，现在我们需要用这个按键表示退出啊，退出游戏啊"
以及："主要是现在的左上角点击会提示你选择一辆载具出击"

旧语义是**混的**（每轮改出来的）：

| 情况 | 旧行为 |
|---|---|
| 有车 | 弃车 + 关库 |
| 开局没车 | `Restart()` 重开 |
| 中途没车又买得起 | 只弹一句「先选一台载具出击」，**不给退** ← 用户卡在这里 |

新语义：**一律退出这一局、回主菜单**。

```csharp
if (h0.clicked) {
    if (armed) { GUI.matrix = oldMatrix; UiKit.EndScreen(); mm.Restart(); return; }
    _confirmQuitAt = Time.unscaledTime;      // 第一次点 = 进入确认态
}
```
- 两次点击确认（3 秒内再点才退），按钮变成红框「确认退出本局？」，避免误触丢掉整局进度
- 重启前必须先 `GUI.matrix = oldMatrix` —— `Restart()` 里是 `LoadScene`，本帧走不到末尾的复位

验证：`Restart()` 后 `Started=False, timeScale=0, garage=False` —— 封面回来了。

### 10.2 弃车 / 取消换车 从「退出」里拆出去

| 入口 | 行为 |
|---|---|
| O / 「升空观战」 | 弃车（回收进钱包）+ 升空观战 |
| **Esc** | **只关车库**回到战场，车还在就继续开（不再顺手弃车） |
| ← 退出本局 | 结束这一局回主菜单 |

Esc 原来等于"弃车"，和 O 撞在一起，玩家按哪个都像在弃车。
新增 `MatchManager.CancelGarageSwap()` 清掉按 G 时挂的旧车回收账。
验证：按 G 后 `pending=70` → Esc 后 `player=True, pending=0`（车没卖、账清了）。
