## 2. 飞机的 bug：`UpdateAir` 完全没检测建筑

`VehiclePhysics` 有两套互不相干的移动逻辑：

| 域 | 方法 | 有没有障碍检测 |
|---|---|---|
| 陆 / 海 | `UpdateGround()` | ✅ 有 `IsBlockedByObstacle()` |
| **空** | `UpdateAir()` | ❌ **完全没有** |

`UpdateAir` 只有一条“撞地”判定：

```csharp
// 旧代码：只判地形高度
if (pos.y < groundY + airCrashHeight) { stateText = "坠毁"; Crash(); return; }
```

**楼顶在 y≈44 m，飞机飞在 y≈200 m，这条判定永远不触发。**
俯冲进楼的飞机直接从楼里穿过去。

实测证据：把战斗机放到 `waste_block_mid` 的**正中心**（楼内），它活得好好的，然后飞走了。

### 修法

在位移之后加一段 **SphereCast 扫掠**（不是只测当前点）：

```csharp
Vector3 prevPos = transform.position;
transform.position += transform.forward * speed * dt;
ClampToBounds();

if (Mathf.Abs(speed) > 2f)
{
    Vector3 flyDir = transform.forward * Mathf.Sign(speed);
    float flyDist = Mathf.Abs(speed) * dt + airCrashRadius;
    var hitsAir = Physics.SphereCastAll(prevPos, airCrashRadius, flyDir,
                      flyDist, ~0, QueryTriggerInteraction.Ignore);
    foreach (var h in hitsAir)
    {
        if (hc is TerrainCollider) continue;                      // 地形交给"撞地"判定
        if (hc.transform.IsChildOf(transform)) continue;          // 自己的零件
        if (hc.GetComponentInParent<VehicleCombat>() != null) continue;  // 其他载具
        if (hc.GetComponentInParent<Projectile>() != null) continue;     // 刚打出去的弹
        if (hc.GetComponentInParent<Torpedo>() != null) continue;

        stateText = "撞楼坠毁";
        Crash();
        return;
    }
}
```

**为什么用扫掠不用点检测**：45 m/s 在 30 fps 下一帧就是 1.5 m，低帧率卡顿可能跨十几米，
只测当前点会漏掉撞进去的那一帧。

新增字段：`airCrashRadius = 3f`（检测球半径）。

## 4. 🔴 我这一轮踩的两个测试坑（下任别再踩）

### 坑 ①：`Collider.bounds` 在同一帧内不随 `transform.position` 更新

我先把坦克 `transform.position` 设到楼前，紧接着读 `Collider.bounds` 去算间隙 ——
读到的是**103 米外的旧位置**（刚出生点），于是所有建筑都测出"挡住=False"，
我一度以为坦克会穿楼，查了半小时。

**正解**：改完 transform 必须调一次
```csharp
Physics.SyncTransforms();
```
这是 PhysX 的权威同步入口。调完 `bounds` 立刻就是新位置。

### 坑 ②：`EnsureHitCollider()` 在 `Start()` 里才跑

`DeployPlayer()` 之后同一帧 `GetComponent<Collider>()` 返回 **null** ——
而 `IsBlockedByObstacle` 第一行就是 `if (col == null) return false;`，
于是测试结果全是"不挡"。

**正解**：要么等一帧，要么手动反射调一次
`VehicleCombat.EnsureHitCollider()`。
