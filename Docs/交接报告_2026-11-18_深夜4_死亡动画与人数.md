## 1. 死亡动画没了 / 死的一瞬间就进商店

**根因**：`MatchManager.Update` 里那段"攒够钱自动弹库"的分支**不等 `garageDelay`**：

```csharp
// 旧
if (Player == null && !_garageOpenForGold && CanAffordCheapest && !GarageScreen.IsOpen)
    OpenGarage(...);          // ← 玩家一死、只要还买得起，下一帧就弹库
```

而 `OnVehicleDestroyed` 里排的是 `_garageAt = Time.unscaledTime + garageDelay(2.5s)`。
两条路打架，前者永远赢 → 2.5 秒的死亡爆炸/残骸全被车库盖住。

**修法**：加 `_garageAt <= 0f`（手上有待执行的弹库排程时让路）。

```csharp
if (Player == null && !_garageOpenForGold && CanAffordCheapest && _garageAt <= 0f
    && (GarageScreen.Instance == null || !GarageScreen.Instance.IsOpen))
```

**实测（MCP，Play）**：
```
destroy 时刻 t=224.60   立刻读 _garageAt=227.10   差=2.50 秒   车库=False   _garageOpenForGold=False
```
即：销毁瞬间车库不开、`_garageOpenForGold` 没被置位、2.5 秒后才由 `OpenGarageForRespawn` 正常弹出。

> ⚠️ 踩过的坑：第一次用「destroy → sleep 0.8s → 查车库」测得车库已开，
> 以为是没修好。实际是 **MCP 每次工具往返本身就有 1~2 秒延迟**，墙钟早过了 2.5 秒。
> 正确做法：**在同一次脚本调用里**记 `t0` 并立刻读 `_garageAt`，看差值。

## 2. 人数上限到底多少 / 全拉到最大场上却没那么多

### 2.1 真实上限（`MatchSettings.MaxPerType = 6`）

| 类型 | 每方 AI 上限 | 两方合计 |
|---|---|---|
| 舰艇 | 6 | 12 |
| 轻型坦克 | 6 | 12 |
| 主战坦克 | 6 | 12 |
| 重装坦克 | 6 | 12 |
| 飞机（战斗+攻击） | 6 | 12 |
| **合计** | **30 AI + 你 = 31** | **61** |

**坦克 = 轻 6 + 主 6 + 重 6 = 18 台/方**（两方 36）。
**飞机 = 6 台/方**（下面这条 bug 修完后是 3 战斗机 + 3 攻击机）。

### 2.2 全 6 实测（配置确实全部生效）

```
配置 AI 30+30  unlock=0
units=61  场上载具=60  我方=30 敌方=30  陆/海/空=36/12/12
重装坦克 12 / 主战坦克 12 / 炮艇 12 / 轻坦 12 / 攻击机 6 / 战斗机 6
```

### 2.3 那为什么"看起来没这么多"

1. **空战默认 3 分钟后才开放**（`UnlockMinutes=3`）。开局只有陆战 36 台（18+18），
   海 12 台和空 12 台是**到点才出场**（`firstSpawnPending`）。开局数一下只有陆战，很正常。
2. 战斗过程中被击毁的 AI 要**攒够钱才复活**（`UpdateRespawns` 里 `u.gold < cost` 就每 2 秒重试），
   所以中后期数量会掉到满编以下 —— 这是经济系统的设计，不是没生成。
3. 2 km × 2 km 地图上 60 台分居两端，视野里同时看得到的本来就没几台。

### 2.4 顺带查出一个真 bug：攻击机从来没生成过

`MatchSettings.BuildAiRoster()` 原来只有：
```csharp
Add(IdFighter, CountOf(team, IdFighter));   // 飞机槽位全给战斗机
```
`IdAttacker`（攻击机，450 血 / 反坦克弹）**一次都没被加进名册** —— 模型、数值、缩略图都做了，
却永远不上场。

改成按槽位交替混编：
```csharp
int airN = CountOf(team, IdFighter);
for (int i = 0; i < airN; i++) list.Add(i % 2 == 1 ? IdAttacker : IdFighter);
```
实测名册：`飞机 6 台 = 战斗机 3 + 攻击机 3`；场上也是 `攻击机 6 / 战斗机 6`（两方各 3+3）。
