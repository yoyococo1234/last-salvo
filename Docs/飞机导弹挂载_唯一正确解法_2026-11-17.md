## 0. 一句话

**导弹挂载必须在「飞机根节点的局部空间」里摆，不能进网格空间算。**
坐标语义：`localPos.x = 右`、`localPos.y = 上`、`localPos.z = 前`，`localRotation = identity`。

## 1. 正确写法（照抄，别改）

```csharp
// ---- 只取一个标量：飞机世界翼展（米）----
var mb = mf.sharedMesh.bounds;
Vector3 lossy = mf.transform.lossyScale;
Vector3 worldSize = new Vector3(
    Mathf.Abs(mb.size.x * lossy.x),
    Mathf.Abs(mb.size.y * lossy.y),
    Mathf.Abs(mb.size.z * lossy.z));
float spanWorld = Mathf.Max(worldSize.x, Mathf.Max(worldSize.y, worldSize.z));

// 飞机根节点的世界缩放（世界米 → 根节点本地单位）
Vector3 rootScale = transform.lossyScale;
float s = Mathf.Max(0.0001f, Mathf.Max(Mathf.Abs(rootScale.x),
                    Mathf.Max(Mathf.Abs(rootScale.y), Mathf.Abs(rootScale.z))));

float missileLenWorld = Mathf.Clamp(spanWorld * 0.062f, 0.6f, 2.2f);
float L = missileLenWorld / s;                       // 本地单位
float D = missileLenWorld * 0.145f / s;
float halfSpanLocal = (spanWorld * 0.5f) / s;
float downOffset = (missileLenWorld * 0.145f * 1.35f) / s;

// ---- 摆弹：直接给 localPosition，不碰网格顶点 ----
Vector3 localPos;
if (count == 1)
    localPos = new Vector3(0f, -downOffset, 0f);              // 单发 → 机腹中线
else
    localPos = new Vector3(side * halfSpanLocal * t, -downOffset, 0f);   // 多发 → 机翼下

m.transform.SetParent(transform, false);
m.transform.localPosition = localPos;
m.transform.localRotation = Quaternion.identity;   // 弹体沿本地 +Z = 飞机前方
```

## 2. 🔴 关键事实：两种飞机的模型尺度差 100 倍

**这是整件事最难的地方，也是我改了一整天都没修对的原因。**

| | 攻击机 `air_attacker` | 战斗机 `air_fighter` |
|---|---|---|
| 网格 bounds size | **17.60 × 17.53 × 5.59**（真实米） | **0.09 × 0.11 × 0.05**（厘米级） |
| Model 节点 lossyScale | **0.60** | **100.00** |
| Model 节点 rotation | (270.02, 90.00, 0) | (270.00, 270.00, 0) |
| 世界翼展 | 10.56 m | 10.57 m |
| 顶点数 | ~10 万 | 45252 |

**世界翼展几乎一样（10.56 vs 10.57），但网格空间差了 100 倍。**

所以：**任何写死的米数常数（如 `-0.18f`）在战斗机身上会被放大 100 倍。**
我写 `bestZ - 0.18f`，在攻击机上是 0.18 米，在战斗机上是 **18 米** ——
MCP 实测战斗机导弹 `up = -18.00`，飞到 18 米外，完全看不见。

## 3. 我踩过的五个坑（按时间顺序）

### 坑 ① 用 `if (v.z < -1.6f) continue;` 排除"起落架"
把**机翼下表面整个排除了**（下表面就是 z 最小的点），弹被挂到机身中部偏上。

### 坑 ② `bestY = ys[i]` 取"最低点那个顶点的 y"
MCP 实测 x=4.23 处：最低 z=-0.70 出现在 **y=-0.9**（翼根前缘），
弹被拉到机身前方（实测 y=+2.05/+1.81/+1.60），不是机翼中段。

### 坑 ③ `z < medianZ - 1.2f` 排除阈值太狠
把真正的最低点排掉了，弹的 z **比该处机翼最低点还高** ——
用户说"掉到下面去了"，其实是掉到机翼**上面**去了。

### 坑 ④ 用**网格局部坐标**验证，报了一堆假"✅"
我一直拿 `InverseTransformPoint` 反算的局部坐标判断"是否在下方"，
但模型 `rotation=(270,90,0)`，网格 z 轴映射到世界 **+Y**（上方）。
换成**世界坐标**（`Vector3.Dot(rel, plane.transform.up)`）一测，
8 枚弹的 up 分量全是 **+1.12~+1.51**，全在飞机上方。

### 坑 ⑤（最致命）在网格空间算坐标 + `TransformPoint` 转世界
模型节点的旋转/缩放组合极多，任何一处搞错就让导弹整体飞出去。
用户截图："越修越坏"、"怎么都脱离了" —— 导弹飘在离机身很远的地方。

**✅ 最终解法：完全绕开网格空间。** 只在飞机根节点局部空间给 `localPosition`，
尺寸只从"世界翼展"取一个标量再除以根节点缩放。**不碰网格顶点、不做 TransformPoint。**

## 4. 验证脚本（必须用世界坐标）

```csharp
// ❌ 错误：拿网格局部坐标验证（会骗你）
Vector3 relLocal = mf.transform.InverseTransformPoint(m.transform.position) - mb.center;

// ✅ 正确：拿世界坐标 + 飞机自身轴验证
Vector3 rel = m.transform.position - plane.transform.position;
float up    = Vector3.Dot(rel, plane.transform.up);      // 应 < 0（在下方）
float right = Vector3.Dot(rel, plane.transform.right);   // 左右位置
float fwd   = Vector3.Dot(rel, plane.transform.forward); // 前后位置
float ang   = Vector3.Angle(m.transform.forward, plane.transform.forward);  // 应 ~0°
```

验收标准：

| 项 | 要求 |
|---|---|
| `up` | < 0，且 > -spanWorld×0.15（在下方但不能飞出去） |
| `abs(right)` | < spanWorld×0.6（在翼展范围内） |
| `ang`（朝向） | < 10°（弹体沿机身前后） |
| 数量 | 攻击机 8（`ammoCapacity` 8），战斗机 1（`ammoCapacity: 1`） |
