## 2. 四条经济规则

### ① 复活递增 1.05

```
第 n 次死后的车价 = 车价 × 1.05^n
```

主战坦克（220 金）实测：

| 死亡次数 | 价格 | 系数 |
|---|---|---|
| 0 | 220 | 1.000 |
| 1 | 231 | 1.050 |
| 2 | 243 | 1.105 |
| 3 | 255 | 1.159 |
| 4 | 267 | 1.214 |
| 5 | 281 | 1.277 |
| 6 | 295 | 1.341 |
| 7 | 310 | 1.409 |
| 8 | 325 | 1.477 |

**1.05 很温和**（用户选的），死 8 次才涨 48%。对比原方案的 1.22（死 8 次涨 5 倍）。

**这是删掉"3 条命"后的替代品**：死亡有代价，但不会一次死亡就断送整局。

### ①-b 换车递增 1.05（同复活系数）

按 G 换车同样 ×1.05^n，**和复活递增共用 1.5 的封顶**。

### ①-c 总倍率封顶 1.5

`MatchManager.MaxPriceMul = 1.5f`

实测（主战 220 金）：

| 死亡次数 | 换车次数 | PriceFor | 倍率 |
|---|---|---|---|
| 0 | 0 | 220 | 1.000 |
| 1 | 0 | 231 | 1.050 |
| 5 | 0 | 281 | 1.277 |
| 8 | 0 | 325 | 1.477 |
| **10** | 0 | **330** | **1.500 ★** |
| 30 | 0 | 330 | 1.500 ★ |
| 0 | 8 | 325 | 1.477 |
| 0 | **15** | **330** | **1.500 ★** |
| 8 | 3 | 330 | 1.500 ★ |
| 100 | 100 | 330 | 1.500 ★ |

**不管死多少次、换多少次，车价最多 330（原价 220 × 1.5）。**

为什么需要封顶：1.05 单看很温和，但**乘起来**会指数级叠加
（死 8 次 × 换 5 次 ≈ 1.48 × 1.28 = 1.89 倍），后期直接买不起车、只能看别人打。

### ② 换车回收 50%

按 G 换车时，旧车按「**它当初的售价 × 50%**」折回钱包。

实测：
```
金币 1000 → 出击主战（220）→ 金币 780
              回收价 = 220 × 50% = 110
换装重装：PriceFor = 260 - 110 = 150
          金币 780 - 150 = 630  ✅
```

**为什么要有这个**：以前换车 = 旧车消失 + 钱全打水漂，"换车"永远不划算，玩家只能一台车开到底。回收一半之后，换车是"亏一半换一个更合适的"，变成真正的战术选择。

### ③ 生存补贴 +5/10s（仅活着）

用 `MatchDef.survivalIncome = 5`（这个字段写了很久，**代码从没读过**）。

实测单周期：
```
有车：占点 15 + 生存 5 = 20   ✅
没车：占点 15（无补贴）       ✅
```

**作用**：奖励"在场"，抑制挂机不出车。也让"活着占点"比"死了等钱"更划算。

### ④ 反雪球系数

| 局面 | 系数 |
|---|---|
| 落后（VP < 对方 × 0.6） | **×1.3** |
| 均势 | ×1.0 |
| 领先（VP > 对方 × 1.5） | **×0.85** |

实测：
```
均势 100:100 → 1.0  ✅
落后 50:100  → 1.3  ✅
领先 200:100 → 0.85 ✅
开局 0:0     → 1.0  ✅（避免除零）
```

压缩"一边倒的垃圾时间"，但不会让领先方白打。
