## 1. 积分上涨倍率（游戏调整面板）

### 界面

`游戏调整` 面板左列，AI 强度下面新增一行：

```
积分上涨倍率    [慢] [较慢] [标准✓] [较快] [快] [极快]
×1.00 · 占满 3 点约 8.3 分钟到 1500 · 只占 1 点约 25.0 分钟
```

**实时显示换算** —— 选中哪档，下面就告诉你"占 3 点 / 占 1 点各要多久到 1500"，不用自己算。

### 档位与上下限

| 档位 | 倍率 | 占 3 点到 1500 | 占 1 点到 1500 |
|---|---|---|---|
| 慢 | **0.50** | 16.7 分钟 | 50.0 分钟 |
| 较慢 | 0.75 | 11.1 分钟 | 33.3 分钟 |
| **标准**（默认） | **1.00** | **8.3 分钟** | 25.0 分钟 |
| 较快 | 1.50 | 5.6 分钟 | 16.7 分钟 |
| 快 | 2.00 | 4.2 分钟 | 12.5 分钟 |
| 极快 | **3.00** | 2.8 分钟 | 8.3 分钟 |

**硬上下限**：`VpRateMin = 0.5` / `VpRateMax = 3.0`，`Clamp` 在 `MatchSettings.Clamp()` 里强制。

### 为什么要有这个

两局模拟发现 VP 速率方差极大：
- 占 3 点 → 9.8 分钟到 1500（太快）
- 各占 1 点 → 15 分钟只到 886（永远打不满）

与其我猜一个"最优值"，不如让玩家自己调。

### 实现

`MatchSettings.cs`：
```csharp
public static float VpRateMul = 1f;
public static readonly float[] VpRateSteps = { 0.5f, 0.75f, 1f, 1.5f, 2f, 3f };
public static readonly string[] VpRateNames = { "慢", "较慢", "标准", "较快", "快", "极快" };
public const float VpRateMin = 0.5f;
public const float VpRateMax = 3f;
```

`MatchManager.UpdateVp()`：
```csharp
float mul = Mathf.Clamp(MatchSettings.VpRateMul, VpRateMin, VpRateMax);
float period = vpPerZoneSeconds / Mathf.Max(0.01f, mul);   // 倍率越高周期越短
```

**为什么用 `1/mul` 而不是直接乘 VP 增量**：直接乘会出现 `0.7 VP` 这种小数，HUD 上跳得很难看。
缩短周期保持"整数周期结算"，VP 永远是整数。

### 实测

调 10 次 `UpdateVp(1.0)`（= 10 秒），3 点全占：

| 倍率 | 实测 VP | 预期 | 结果 |
|---|---|---|---|
| ×0.5 | +15 | +15 | ✅ |
| ×1.0 | +30 | +30 | ✅ |
| ×2.0 | +60 | +60 | ✅ |
| ×3.0 | +90 | +90 | ✅ |

**完全精确。**

## 2. 灵魂出窍按键（按键设置面板）

### 界面

`按键设置` 面板右列最后一行新增：

```
灵魂出窍（观战）    [O]
```

和其他键一样：点击 → "按新键…" → 按键 → 冲突检测（重复键会被拦下）。

### 🔴 关键：HUD 提示跟着变

用户特别交代：
> "注意到游戏内部灵魂出窍的时候下面有按键提示，这个到时候如果玩家改了，你也得改"

`SoulCamera.HintText` 改成**动态读 Bindings**：

```csharp
public static string HintText
{
    get
    {
        string exitKey = Bindings.Get(Bindings.Act.Soul).ToString();
        return $"灵魂视角 · WASD 飞 / Space 升 / Shift 降 / Alt 加速 / 滚轮调速 / {exitKey} 退出";
    }
}
```

**实测验证**：
```
默认:  灵魂视角 · WASD 飞 / ... / O 退出
改成 K: 灵魂视角 · WASD 飞 / ... / K 退出   ✅ 跟着变了
```

### 实现

`Bindings.cs`：
```csharp
public enum Act { ..., LevelFlight, Soul }

new Entry { act = Act.Soul, label = "灵魂出窍（观战）", def = KeyCode.O },
```

`SoulCamera.Update()`：
```csharp
if (Active && Bindings.Down(Bindings.Act.Soul)) { Exit("手动退出"); return; }
```
