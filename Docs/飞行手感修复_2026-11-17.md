## 1. 为什么烂 —— 就一个参数

`VehiclePhysics.airRecenterSpeed` 原来是 **0.5**。

它的意思是"虚拟摇杆每秒回中多少"，0.5 就是 **2 秒才归零**。

而这 2 秒里飞机一直按最高角速度在转。

### 按代码公式算出来的真实数字

```
场景：鼠标往上推 0.2 秒就松手（一次很轻的点按）

旧参数（回中 0.5）：
  飞机继续转 2.00 秒
  累计俯仰 86°   ← 整机几乎翻过来

新参数（回中 3.5）：
  松手即停
  累计俯仰 7°
```

**86° 意味着什么**：你只想抬头看一眼，结果飞机直接指天。

于是玩家的实际体验是：
- 手指轻点 → 飞机翻跟头（过度敏感）
- 想稳住 → 得反着推鼠标（难控）
- 想持续转弯 → 得拼命甩鼠标（不跟手）

**又飘又迟钝，两个毛病同时存在** —— 这就是"烂"的全部原因。

顺带说个历史：这个值 2026-11-12 从 0.9 降到 0.5（注释写"长按转向不再被回中顶住"），
那次改动是为了解决"转弯时被回中拽回来"，但代价是彻底失去了精确控制。方向搞反了。

## 2. 怎么修

### 核心

| 参数 | 旧 | 新 | 理由 |
|---|---|---|---|
| **airRecenterSpeed** | **0.5** | **3.5** | 松手 0.29 秒内停住，能精确操控 |
| airPitchRate | 80 | **70** | 回中变快之后 80 会一推就过冲 |
| airYawRate | 40 | **50** | 转弯太迟钝 |
| airRollRate | 110 | **140** | 飞行游戏里滚转是最该利落的轴 |
| airRollFollow（相机） | 0.85 | **0.6** | 地平线跟着斜 85% 太容易晕 |

### 改之后的响应曲线（按公式 + 实测双重验证）

| 鼠标推的时长 | 累计俯仰 |
|---|---|
| 0.1 秒 | **2°** |
| 0.2 秒 | **5°** |
| 0.3 秒 | **9°** |
| 0.5 秒 | **23°** |
| 1.0 秒 | **59°** |

**渐进、可预期** —— 轻点微调，长推大机动。

### 满舵机动能力

| 动作 | 角速度 | 转 90° 要多久 |
|---|---|---|
| 纯俯仰 | 70°/s | 1.3 秒 |
| 纯偏航 | 50°/s | 1.8 秒 |
| 压 90° 杆 + 偏航 | 50 + 42 = 92°/s | 1.0 秒 |

## 3. 实测验证

运行时读到的新值：
```
airRecenterSpeed = 3.5
airPitchRate     = 70
airYawRate       = 50
airRollRate      = 140
```

把虚拟摇杆推满（`_airAimY = 1`），2 秒后：
```
_airAimY = 0          ← 已正确回中
forward  = (0.000, 0.167, 0.986)
俯仰角 ≈ 9.6°         ← 旧参数会是 86°
```

**9.6° vs 86°，精确度提升约 9 倍。**

## 4. 🔴 测试踩的坑（下任注意）

### `VehicleAI.Start()` 会把 `aiControlled` 强制设回 true

我用 `VehicleFactory.Spawn(..., isPlayer: false)` 生成测试机，
然后手动设 `phys.aiControlled = false`，结果测出来的数据完全不对
（一架没碰鼠标的飞机自己转了 180°）。

原因：
```csharp
void Start() { if (_phys != null) _phys.aiControlled = true; }
```

**正解**：测飞行手感必须先 `DestroyImmediate` 掉 `VehicleAI` 组件，
否则 AI 一直抢方向盘。我第一次测出的 180° 就是这么来的。

## 5. 还能继续改的（没做，看你要不要）

| 项 | 说明 |
|---|---|
| **没有能量管理** | 俯冲不加速、爬升不掉速，速度恒在 20~52 m/s。加"俯冲加速 / 爬升减速"会真实很多 |
| **没有失速** | 抬头到垂直也不会掉下来 |
| **转弯半径固定** | 不管速度多少，转向角速度一样 |

这三条都是"街机 vs 拟真"的选择。现在偏街机，够玩但不够"飞"。
要往拟真走，我可以加一条 `airspeed ∈ [stallSpeed, maxSpeed]` + 重力分量到速度。
