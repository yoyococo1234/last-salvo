## 1. 🔴 两个真 bug（这才是"差一点点 / 差很多"的根源）

### bug ①：翼展取错了轴

旧代码：

```csharp
float spanWorld = Mathf.Max(worldSize.x, Mathf.Max(worldSize.y, worldSize.z));
```

**两个机型的机长都大于翼展**，所以取到的其实是机长：

| 机型 | 翼展(X) | 机长(Z) | `max()` 取到 |
|---|---|---|---|
| 攻击机 | 10.56 | 10.52 | 10.56（碰巧对） |
| 战斗机 | **8.96** | **10.57** | **10.57（错，偏大 18%）** |

结果：战斗机所有比例都偏大，弹长从 1.16 m 变成 1.79 m。

**修法**：翼展必须取 `size.x`（飞机自身轴系的左右方向），不是三轴最大值。

### bug ②：`downOffset` 跟机翼无关

旧代码：

```csharp
float downOffset = (missileDiaWorld * 1.35f) / s;   // 弹径 × 1.35
localPos = new Vector3(side * halfSpanLocal * t, -downOffset, 0f);
```

弹的高度只按"弹径"往下挪，**完全不知道机翼下表面在哪**。所以弹要么陷进机翼、要么悬空 ——
这正是用户说的"差一点点"（战斗机）和"差很多"（攻击机，机翼有上反角，各处下表面高度差 0.4 m）。

**修法**：见 §2。

## 2. 正确做法（照抄即可）

### 2.1 从网格实测机翼数据

```csharp
// 顶点 → 飞机根节点局部空间（只做这一次变换）
Matrix4x4 toRoot = root.worldToLocalMatrix;
foreach (var mf in model.GetComponentsInChildren<MeshFilter>())
{
    var me = mf.sharedMesh;
    if (me == null || !me.isReadable) continue;
    Matrix4x4 m = toRoot * mf.transform.localToWorldMatrix;
    foreach (var v in me.vertices) pts.Add(m.MultiplyPoint3x4(v));
}
```

### 2.2 自动找机翼的 z 带

机翼 = 哪个前后区间里横向跨度 > 75% 全翼展：

```csharp
for (int i = 0; i < NZ; i++)   // NZ = 48
{
    float z0 = mn.z + lenZ * i / NZ, z1 = mn.z + lenZ * (i + 1) / NZ;
    float a = float.MaxValue, b = float.MinValue;
    foreach (var q in pts)
        if (q.z >= z0 && q.z < z1) { a = Min(a, q.x); b = Max(b, q.x); }
    if ((b - a) / span > 0.75f) { wz0 = Min(wz0, z0); wz1 = Max(wz1, z1); }
}
```

实测结果：
- 攻击机：机翼 z 带 `[-1.05, 1.05]`（弦长 2.10 m）
- 战斗机：机翼 z 带 `[-2.86, -0.48]`（三角翼，弦长 2.38 m）

### 2.3 🔴 在挂点**实际位置**做二维局部采样（关键）

```csharp
public void LocalSurface(float x, float z, float window, out float yBot, out float yTop, out int hits)
{
    yBot = float.MaxValue; yTop = float.MinValue; hits = 0;
    foreach (var q in rawPts)
    {
        if (Mathf.Abs(q.x - x) > window) continue;
        if (Mathf.Abs(q.z - z) > window) continue;
        yBot = Mathf.Min(yBot, q.y);
        yTop = Mathf.Max(yTop, q.y);
        hits++;
    }
}
```

**为什么不能用一维 `|x|` 分桶**：桶里取的是整条翼弦范围内的极值，
机翼上方的**发动机短舱**会把"上表面"顶到很高，算出来的"翼厚"是假的，
挂架按假翼厚埋进去就会**从机翼上表面穿出来**（我踩过，渲染图里翼面上冒出几个方块）。

窗口宽度：攻击机 `halfSpan * 0.05`，战斗机机腹 `0.16 m`（必须小，否则把垂尾框进来）。

### 2.4 挂架埋入深度 = 局部翼厚的 75%

```csharp
float wingThk = Mathf.Max(D * 0.5f, wingTopY - wingY);
float bury = wingThk * 0.75f;   // 留 25% 余量不穿出上表面
```

实测埋入 0.095~0.132 m，翼厚 0.38~0.53 m —— 焊死且不穿模。

### 2.5 单发（战斗机机腹）

```csharp
float pz = Mathf.Lerp(pf.wingZ0, pf.wingZ1, 0.25f);   // 靠前，让开主起落架舱
pf.LocalSurface(0f, pz, 0.16f, out float bellyBot, out float bellyTop, out int bHits);
float bodyThk = D * 0.55f;   // 机腹挂弹"贴腹"，只需埋一点点
```

**别用机身厚度的一半**：我试过，战斗机算出 1.85 m 的挂架，侧视像吊着一根棍子。

## 3. 弹体尺寸（按翼展比例，不写死米数）

```csharp
float spanWorld = pf.halfSpan * 2f * s;
float lenWorld  = Mathf.Clamp(spanWorld * 0.20f, 0.9f, 2.8f);   // 多发
float diaWorld  = lenWorld * 0.115f;

if (count == 1)  // 单发（战斗机机腹）用更短的弹
{
    lenWorld = Mathf.Clamp(spanWorld * 0.13f, 0.8f, 1.6f);
    diaWorld = lenWorld * 0.13f;
}
```

依据：AGM-65 长 2.5 m / A-10 翼展 17.5 m ≈ 0.14；AIM-9 长 3.0 m / 翼展 9 m ≈ 0.33（外挂机翼）。
机腹半埋挂架用更紧凑的比例。

实测输出：
- 攻击机：翼展 10.56 → 弹长 2.11 m，弹径 0.24 m
- 战斗机：翼展 8.96 → 弹长 1.16 m，弹径 0.151 m

## 4. 挂点分布

多发（攻击机 8 枚）：

```csharp
float t = perSideCount <= 1 ? 0.52f
        : Mathf.Lerp(0.44f, 0.80f, row / (float)(perSideCount - 1));
// t = |x| / halfSpan，0=机身中线，1=翼尖
```

- **起始 0.44**：攻击机 `t < 0.40` 是发动机短舱和主起落架，不能挂弹（实测 t=0.30~0.36 的 ymin 是 -1.67，那是起落架）
- **终止 0.80**：再往外机翼太薄，而且靠近翼尖副翼
