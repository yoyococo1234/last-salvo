## 1. 🔴 鱼雷装填 bug（用户："这巴不对"）

### 真因

`VehicleCombat` 只有**一个** `float _nextFireTime`，主炮和鱼雷共用：

```csharp
// 旧代码
float _nextFireTime;

bool CanFire => ... && Time.time >= _nextFireTime && ...;

bool FireWeapon(WeaponDef w, ...)
{
    if (!CanFire) return false;        // ← 检查的是**主武器**的装填
    _nextFireTime = Time.time + w.reloadTime;   // ← 写的却是**当前这把**武器
}
```

后果：
- 打完舰炮（4 s 装填）→ `_nextFireTime = now+4` → 鱼雷被锁 4 s
- 发完鱼雷（9 s 装填）→ 舰炮被锁 9 s
- 更糟：`CanFire` 读的是 `Weapon`（当前选中武器），如果当前是鱼雷，`CanFire` 检查鱼雷的 `_ammoLeft`，但计时器是主炮写的那一份 —— 两个语义混在一起

### 修法

改成**按 `def.weapons` 下标各存一个计时器**：

```csharp
float[] _nextFireByWeapon;

float ReloadLeft(WeaponDef w) { int i = Array.IndexOf(def.weapons, w); return Mathf.Max(0, _nextFireByWeapon[i] - Time.time); }
bool ReadyToFire(WeaponDef w) => ReloadLeft(w) <= 0f;
void StartReload(WeaponDef w) { int i = Array.IndexOf(def.weapons, w); _nextFireByWeapon[i] = Time.time + w.reloadTime; }
```

`FireWeapon` 里不再用 `CanFire`，改成只检查**这一把武器自己**：

```csharp
if (!Alive || gunBroken) return false;
if (!ReadyToFire(w)) return false;
if (!HasAmmoFor(w)) return false;
StartReload(w);
```

`CanFire` / `ReloadProgress` 也改成读当前武器自己的计时。`RespawnAt` 里清空整个数组。

### 实测验证

```
炮艇武器：[0] naval_gun reload=4s  [1] torpedo_launcher reload=9s  [2] mg_aa reload=0.11s

给舰炮上装填后：
  舰炮 ReloadLeft = 4.00s   （应 ≈4）
  鱼雷 ReloadLeft = 0.00s   （应为 0 —— 不受舰炮影响）
判定: ✅ 已独立
```

## 4. 灵魂出窍（用户要的"MC 创造模式"）

### 什么时候能用

| 情况 | 行为 |
|---|---|
| **没有载具**（刚被击毁 / 没钱买车） | **自动进入** —— 否则镜头傻停在残骸上 |
| 有载具时按 **O** | 手动进入观战模式，看队友敌人在哪 |
| 重新出击（有车了） | 自动退出 |
| 按 **O** 或再按一次 | 手动退出 |

### 操作（仿 MC 创造模式）

| 键 | 功能 |
|---|---|
| W / S | 前后（沿视线） |
| A / D | 左右平移 |
| Space | 上升 |
| Shift | 下降 |
| **Alt（按住）** | 加速 ×3 |
| 鼠标 | 转视角 |
| 滚轮 | 调基础速度（10~400 m/s） |
| O | 退出 |

### 实现要点

`Assets/Scripts/SoulCamera.cs`（新文件，约 260 行）

**为什么不塞进 `CameraFollow.cs`**：那个文件已经 1020 行，塞了坦克 / 船 / 飞机三套机位、
开镜、机枪分划、滚转跟随。再往里加"自由飞行"会变成**第四个互相打架的入口**
（11-17 我就因为"没搞懂原有三入口就加第四个"踩过坑，见瞄准链路文档）。

做法：**接管相机 transform，但不动 CameraFollow 的任何状态** ——
进入时 `_follow.enabled = false`，退出时恢复 `target` + `enabled`，
CameraFollow 会自己 Lerp 回去。

**防穿地**：`BattlefieldTerrain.SampleHeight` 兜底，高度不低于地面 +2 m，上限 1500 m。
